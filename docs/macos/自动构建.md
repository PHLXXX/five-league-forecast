# macOS 自动构建

macOS 安装包必须在真正的 macOS 构建环境中生成。项目已包含 `.github/workflows/build-macos.yml`，无需在 Windows 上强行制作不完整的 DMG。

## 生成安装包

1. 将完整项目上传到 GitHub 仓库，确认 `.github/workflows/build-macos.yml` 也在仓库中。
2. 打开 GitHub 仓库顶部的“Actions”。
3. 在左侧选择“构建 macOS 桌面版”，点击“Run workflow”。
4. 等待 Apple 芯片和 Intel 两项任务完成。
5. 在任务页面底部下载两个构建产物。每个产物中都包含 DMG 和 ZIP。

`arm64` 供 M 系列 Apple 芯片使用，`x64` 供 Intel Mac 使用。自动流程会先运行全部测试，测试失败时不会发布安装包。

## 正式签名与公证

未签名安装包适合个人测试。面向其他用户长期分发时，建议在 GitHub 仓库的 Actions Secrets 中配置 Apple Developer ID 证书和公证信息，包括 `CSC_LINK`、`CSC_KEY_PASSWORD`、`APPLE_ID`、`APPLE_APP_SPECIFIC_PASSWORD` 与 `APPLE_TEAM_ID`。配置完成后 electron-builder 会在构建阶段使用证书；不要把证书或密码直接写入项目文件。
