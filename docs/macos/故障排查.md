# macOS 故障排查

## 系统提示无法验证开发者

这是未签名测试包的系统保护提示，不代表程序损坏。进入“应用程序”，按住 Control 点击软件，选择“打开”。若用于公开分发，应改用已签名并通过 Apple 公证的安装包。

## 打开后一直停留在启动页

先确认网络可用，再通过应用菜单完整退出后重新打开。分析服务会优先使用 5177 端口，端口被占用时会自动选择其他本机端口。仍无法启动时，可在软件错误页点击“打开日志”，或查看 `~/Library/Application Support/喷火龙五大联赛分析平台/logs/desktop.log`。

## 历史数据没有出现

请确认没有手工删除 `~/Library/Application Support/喷火龙五大联赛分析平台/data`。首次安装会复制基础数据，之后更新程序不会覆盖已有历史。若从另一台电脑迁移，可在两边软件都完全退出后复制这个 `data` 目录。

## 安装包与处理器不匹配

M1、M2、M3、M4 等 Apple 芯片应使用 `arm64`，Intel Mac 应使用 `x64`。选择错误架构可能导致无法打开或性能异常。可点击屏幕左上角苹果菜单，再选择“关于本机”查看芯片类型。
