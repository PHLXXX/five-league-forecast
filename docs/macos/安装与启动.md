# macOS 安装与启动

## 选择正确版本

- 使用 M1、M2、M3、M4 或后续 Apple 芯片的 Mac，请下载文件名包含 `arm64` 的 DMG。
- 使用 Intel 处理器的 Mac，请下载文件名包含 `x64` 的 DMG。
- 系统要求为 macOS 12 Monterey 或更高版本。

## 安装

1. 双击 DMG 文件。
2. 将“喷火龙五大联赛分析平台”拖入“应用程序”文件夹。
3. 从“应用程序”中打开软件。首次启动会准备本地数据，大约需要数秒。
4. 软件只在本机 `127.0.0.1` 启动分析服务，不会向局域网开放端口；联网仅用于更新赛程、积分榜、比赛结果和分析资料。

## 首次打开提示

未使用 Apple 开发者证书签名的测试包，首次双击时可能被系统拦截。请在“应用程序”中按住 Control 点击软件，选择“打开”，再确认一次。正式签名和公证后的安装包不会出现此步骤。

## 数据与退出

历史推荐、回测和缓存数据保存在 `~/Library/Application Support/喷火龙五大联赛分析平台`。覆盖安装新版不会删除这些数据。关闭窗口后应用仍保留在程序坞；点击图标可重新打开。请使用菜单中的“退出喷火龙五大联赛分析平台”或按 `Command+Q` 完整退出并停止本地服务。
