# 五大联赛分析平台本地桌面版设计

## 目标

将现有五大联赛分析网页封装为 Windows 10/11 64 位本地桌面软件。用户无需安装 Node.js、配置命令行或手动打开本地网址，只需联网并双击软件即可使用全部赛程、积分榜、分析、盘口和历史回测能力。

交付物包括安装版、免安装便携版、桌面快捷方式，以及保存在 `E:\喷火龙五大联赛分析工具` 的完整文档和启动说明。

## 方案比较

1. **Electron 桌面封装（采用）**：复用现有 Node/Express 后端与前端，软件自带 Chromium 和 Node 运行时，改造范围小、兼容性高，安装包体积相对较大。
2. **Tauri 桌面封装**：安装包更小，但需要重写或另行携带 Node 后端，当前项目的数据抓取与分析逻辑迁移风险高。
3. **便携 Node 启动器**：实现最简单，但仍依赖浏览器和后台进程，不符合“本地化软件”的使用体验，也容易再次出现服务进程停止后打不开的问题。

## 架构

桌面主进程负责窗口、单实例锁、服务生命周期、联网状态和异常提示。现有 Express 服务作为 Electron 子进程运行，使用软件内置的 Node 环境，不依赖系统安装。主进程启动时分配可用本地端口，设置独立用户数据目录，启动服务并轮询 `/api/health`；健康检查通过后才加载主界面。

```text
Windows 快捷方式
  -> Electron 主进程
     -> 本地 Express 子进程（仅监听 127.0.0.1）
        -> 现有前端与 API
        -> 互联网数据源
     -> BrowserWindow 加载本地服务
```

用户关闭主窗口后，主进程终止服务子进程，防止残留端口。再次启动时只允许一个实例；第二次双击会唤醒已有窗口。

## 数据与配置

- 可写缓存、历史推荐和用户配置存放在 Electron `userData` 目录，不写入安装目录。
- 首次启动时从安装包中的 `data` 模板初始化本地数据，后续更新保留用户历史记录。
- API 密钥通过本机 `.env` 或软件数据目录配置读取，不写入前端代码和文档示例。
- 服务仅绑定 `127.0.0.1`，不向局域网公开端口。
- 无网络时保留已缓存赛程和历史数据，并在界面显示离线状态；实时抓取与深度更新需要联网。

## 桌面体验

- 软件名称：`喷火龙五大联赛分析平台`。
- 默认窗口最小尺寸 1180x760，启动后最大化，保留系统最小化、最大化和关闭按钮。
- 启动阶段显示简洁的深色科技风加载页，包含“正在启动分析服务”和重试状态。
- 服务启动失败时显示中文错误页，并提供“重新启动服务”“打开日志目录”和“退出”操作。
- 外部链接使用系统默认浏览器打开，软件窗口只加载本地可信内容。

## 打包与交付

使用 `electron-builder` 生成：

- NSIS 安装版：支持开始菜单和桌面快捷方式，可正常卸载。
- 便携版：单个可执行文件，适合直接复制使用。
- 构建目录：项目内 `dist-desktop`。
- 最终交付目录：`E:\喷火龙五大联赛分析工具\安装包`。

文档目录 `E:\喷火龙五大联赛分析工具\文档` 包含产品说明、安装说明、启动说明、联网与数据源说明、故障排查、版本信息和构建验证报告。

## 错误处理

- 端口冲突：自动选择新的本地端口，不要求用户处理。
- 服务启动超时：展示中文错误页，并把详细错误写入用户日志目录。
- 网络不可用：界面保持可打开，使用缓存并明确标记离线状态。
- 数据源失败：沿用现有分层回退与缓存机制，不把缓存伪装成实时数据。
- 软件异常退出：下次启动清理遗留进程状态并重新健康检查。

## 测试与验收

1. 未安装系统 Node.js 的 Windows 10/11 64 位环境可启动安装版和便携版。
2. 双击软件后无需命令行，30 秒内进入主界面或显示可操作的中文错误页。
3. 同时双击两次只保留一个窗口和一个后端服务。
4. 首页、五大联赛切换、整季赛程、积分榜、比赛分析和历史回测接口可用。
5. 关闭软件后本地服务端口释放，无残留 Electron 或 Node 子进程。
6. 离线启动时软件仍可打开并显示缓存/离线状态；联网恢复后可刷新数据。
7. 安装版、便携版、文档和校验报告均存在于 `E:\喷火龙五大联赛分析工具`。
