# 版本信息

- 产品名称：喷火龙五大联赛分析平台
- 桌面版版本：1.2.2
- 支持系统：Windows 10/11 64 位、macOS 12 或更高版本
- 覆盖联赛：英超、法甲、德甲、西甲、意甲
- 桌面框架：Electron 43
- 构建工具：electron-builder 26
- 本地服务：Node.js / Express
- 数据时区：界面统一显示北京时间，内部保留 UTC 用于比赛匹配

本版本提供无需系统 Node.js 的本地桌面运行方式。Windows 输出 NSIS 安装版和免安装便携版，macOS 分别输出 Apple 芯片与 Intel 的 DMG/ZIP。运行数据、历史推荐和日志保存在系统用户数据目录，更新软件时不会主动覆盖已有历史记录。

`1.0.1` 修复桌面版因未读取本机 football-data 密钥而无法显示赛程的问题，并增加 ESPN 五大联赛完整赛季赛程自动回退。主源无权限、限流或临时不可用时，赛程列表仍可继续使用。

`1.0.2` 补齐 football-data 与 ESPN 两套球队代码的中文别名，覆盖当前赛季及近五赛季升降级球队。球队显示名按联赛隔离，避免相同缩写在不同联赛发生误译。

`1.0.3` 重做比分强弱校准：积分、排名、净胜球、攻防效率、近10场和主客场信号分别计算，只有多项证据同向时才扩大净胜球预期。新赛季首轮缺少上赛季顶级联赛积分数据的升班马使用保守升班基线，避免强弱场退化成普通主场模型；实时分析与历史回测统一使用更完整的强度范围。

`1.1.0` 增加 macOS 桌面版支持，覆盖 Apple Silicon `arm64` 与 Intel `x64`。应用窗口、程序坞激活、中文原生菜单、用户数据目录和本地服务退出逻辑均按 macOS 规范适配，并加入 GitHub Actions 双架构自动构建与 Retina 图标校验。

`1.2.0` 预测模型与界面重做。

- 预测核心换成 Dixon-Coles 时间加权攻防评级：用近三个赛季五大联赛的进球和 xG（数据来自 football-data.co.uk，免费、无需密钥），越近的比赛权重越高（半衰期一年），升班马使用保守基线。
- 有赔率时把去除抽水后的市场概率按 85% 权重融合；没有赔率时用纯模型。原来叠加的 FIFA 排名、东道主、海拔、网页词频等未经验证的启发式调整不再影响概率。
- 首选比分改为“与胜平负首选一致的最高概率比分”，不再出现推荐主胜却给 1-1 的矛盾。
- 回测（2023/24 至 2026/27 赛季共约 5,700 场，逐场只用赛前数据）：胜平负命中率由旧模型约 50% 提升到约 54%，对数损失由 1.04 降到 0.97，大小 2.5 与 Top3 比分同样提升，已接近博彩市场水平。
- 修复 ESPN 不再支持按日期区间拉取整季赛程（HTTP 400）导致未配置 football-data 密钥时赛程加载失败的问题：改为逐队拉取赛程合并。
- 全新界面：浅色/深色自动切换，赛程列表直接显示每场胜平负概率与首选比分，比赛页包含概率条、比分概率矩阵、进球数分布、公平亚盘、模型与市场对比、球队攻防与近况（含 xG），回测页增加概率校准图与市场对照。

`1.2.1` 赛程、盘口、体彩核对。

- 赛程：球队赛程请求失败自动重试；用 ESPN 整季比赛清单补齐延期/中断场次（此前西甲巴列卡诺 vs 毕尔巴鄂会漏掉）；修正“中断”被误判为完场 0-0。已逐场核对本赛季与上赛季五大联赛，比分与日期和 football-data.co.uk 完全一致。
- 盘口：统一使用 ESPN/DraftKings 实时盘口，按比赛编号精确匹配（不再靠队名猜）；列表页与比赛页同一份数据。比赛页显示欧赔、初盘到现盘的变化、真实大小球线与让球线，以及模型对这两条线的概率。
- 体彩：新的竞彩对阵匹配（简称表 + 主客队、日期、联赛三项同时吻合）；体彩官网目前对程序启用了防爬验证（EdgeOne 567），取不到时明确提示，并给出与主预测同口径的四项模型推导；拦截解除后自动恢复官方受注与固定奖金。

`1.2.2` 推荐命中率统计。

- 赛程预测页顶部新增“推荐命中率统计”条：本赛季五大联赛与世界杯留档的胜平负、大小 2.5、比分、体彩胜平负命中率，点“查看明细”进入详情。
- 原“赛前留档”页改名“推荐命中率”，可切换当前联赛 / 五大联赛合计 / 世界杯留档；新增大小 2.5 命中率与体彩四种玩法命中率；原先误标为“大小球”的指标更正为“总进球数命中”。
- 世界杯期间保存的 59 条推荐重新纳入统计，赛果来自 ESPN；淘汰赛打了加时的按 90 分钟比分核验。
