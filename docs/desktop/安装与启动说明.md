# 安装与启动说明

## 安装版

打开 `安装包` 文件夹，双击名称中包含“安装版”的 `.exe` 文件。根据安装向导选择目录并完成安装，安装程序会创建桌面和开始菜单快捷方式。以后双击“喷火龙五大联赛分析平台”即可启动。

## 便携版

双击名称中包含“便携版”的 `.exe` 文件即可使用，不需要安装。建议把便携版放在固定目录，不要在软件运行时移动或删除文件。便携版和安装版都会把缓存、历史推荐和日志保存在当前 Windows 用户的数据目录中。

## 正常启动流程

1. 确认电脑已经联网。
2. 双击软件，先看到“正在启动分析服务”页面。
3. 软件自动初始化缓存并检查本地服务，完成后进入五大联赛主界面。
4. 首次联网更新可能比后续启动稍慢；不要重复双击，软件只会保留一个实例。

## 退出软件

点击窗口右上角关闭按钮即可完整退出。软件退出时会同时停止本地分析服务，不需要在任务管理器中手动结束 Node 或 Electron 进程。

## 日志位置

如果启动失败，错误页面可点击“打开日志目录”。默认日志位于 `%APPDATA%\喷火龙五大联赛分析平台\logs\desktop.log`。提交故障时请提供该日志文件和出现问题的时间。
