# 联网与数据说明

软件本体可以离线打开，但实时赛程、积分榜、天气、情报、盘口和深度分析需要联网。网络暂时不可用时，软件会尝试显示上次成功保存的缓存，并标记数据时间；缓存不等同于实时数据。

主要结构化数据包括五大联赛赛程、完场比分、积分榜、球队状态和比赛事件。完整赛季赛程优先使用 football-data.org；密钥缺失、无权限、限流或主源临时故障时会自动切换 ESPN Soccer API。天气与地理信息优先使用公开结构化接口；盘口、角球、罚牌和情报会根据可用性组合多个来源。任何未获得稳定盘口来源的市场都应显示“暂无可验证盘口”，不会把模型基线伪装成真实盘口。

部分数据源需要单独的 API 密钥。未配置密钥时软件仍可使用公开来源和本地缓存，但覆盖范围或更新速度可能下降。密钥只应保存在本机环境配置中，不要截图公开，也不要写入分享文档。

桌面版会自动读取 `%APPDATA%\喷火龙五大联赛分析平台\.env`。如需配置密钥，可新建该文件并按一行一个变量填写，例如：

```text
FOOTBALL_DATA_API_KEY=你的密钥
ODDS_API_KEY=你的密钥
PINNACLE_GUEST_API_KEY=你的密钥
```

修改后完全退出软件并重新打开即可生效。安装目录和便携版 EXE 内不保存密钥，因此更新或更换程序文件不会覆盖本机配置。

软件只在本机 `127.0.0.1` 地址启动分析服务，不对局域网或公网开放。外部网页链接会使用系统默认浏览器打开，桌面软件窗口不会直接加载不受信任的网站页面。
