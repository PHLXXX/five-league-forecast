# 喷火龙五大联赛分析平台

本软件是面向英超、法甲、德甲、西甲和意甲的 Windows 与 macOS 本地赛事分析工具，提供整季赛程、积分榜、完场赛果、比赛分析、盘口参考和历史回测。软件界面与分析服务都运行在本机，联网后会从可用数据源更新赛程、结果、天气、市场信息和赛事情报。

桌面版自带运行环境，不要求电脑安装 Node.js，也不需要使用命令行或手动输入本地网址。软件启动后会自动建立仅限本机访问的分析服务，健康检查通过后打开主界面；关闭软件时会同步关闭服务。

分析结论仅用于信息研究与比赛观察，不保证结果，也不构成收益承诺。不同数据源可能存在延迟、缺失或口径差异，软件会优先展示经过结构化核验的数据，并对缓存、模型基线和实时数据进行区分。

运行环境：Windows 10/11 64 位，或 macOS 12 及更高版本；需要可用网络连接，建议至少 4 GB 内存和 1 GB 可用磁盘空间。
